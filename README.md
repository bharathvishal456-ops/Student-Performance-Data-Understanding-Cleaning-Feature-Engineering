

The dataset contains the following columns:

- Student_ID
- Name
- Age
- Gender
- Course
- Maths
- Python
- English
- Computer_Science
- Attendance_Percent
- CGPA
- Assignment_Submitted
- Performance

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Data Cleaning

The following cleaning operations are performed:

1. Check for missing values.
2. Check duplicate records.
3. Verify data types.
4. Check invalid values.
5. Handle missing or duplicate data if present.

## Feature Engineering

New useful features can be created from the existing columns, such as:

- Average Marks
- Total Marks
- Attendance Category
- Performance Score


## Data Analysis

The project can be used to analyze:

- Student average marks.
- Attendance and performance.
- Subject-wise performance.
- CGPA distribution.
- Pass and fail students.
- Assignment submission and performance.
